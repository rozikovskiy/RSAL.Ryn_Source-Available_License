# What is RSAL?

RSAL (Ryn Source-Available License) is a custom open-source license (source-available) designed to protect intellectual property, authorship, and brand, while allowing flexible commercial and proprietary use under certain conditions.

### Key Features of RSAL

Soft integration: Allows developers to incorporate licensed software into private, commercial, or closed codebases without having to open the source code of the surrounding project.

The 60% codebase threshold: If the software constitutes more than 60% of the total code in the project or operates in a closely related area, mandatory attribution to Ryn Corporation and the original authors is required.

Brand and name protection: prevents unauthorized rebranding or repackaging of standalone software as an independent competing product under a fictitious name, and also protects Ryn’s trademarks.

Protection against circumvention: prohibits intentional code obfuscation or automatic transpilation aimed primarily at bypassing the 60% attribution threshold or concealing the structural origin of the software.

# Why RSAL exists?

RSAL emerged quite by accident — at the moment when it became clear that there simply was no ideal option among the existing licenses for utilities and tools.

### The existing solutions fell into extremes:

Licenses that are too restrictive require developers to fully open‑source their own product.

Licenses that are too permissive leave loopholes, allowing unscrupulous developers to profit from someone else’s work by changing just a couple of lines of code and passing off someone else’s work as their own.

That is why it was decided to create our own license, which does not require the disclosure of proprietary code but still establishes clear and fair boundaries and conditions for copyright protection.
